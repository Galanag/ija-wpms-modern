# UAT Acceptance

## P0 runtime

- web starts
- API starts
- database connects
- login works
- session/CSRF works

## P1 administration

- create/edit/archive organizational units
- parent/child validation
- user assignment
- manager assignment
- role/module access
- master data CRUD

## P2 planning/finance

- strategy → goal → objective → activity → KPI
- request → approval → budget → lines → finance
- annual plan allocation remains independent from operational budget lines

## P3 workforce

- employee plan
- assigned activity/KPI
- execution
- evaluation
- supervisor approval

## P4 reporting

- global filters
- dashboard drilldown
- exports
- source reconciliation

## P5 attachments

- upload
- replace
- secure download
- delete/archive

All claims must be marked PASS, FAIL or UNVERIFIED; test counts alone are not acceptance evidence.
